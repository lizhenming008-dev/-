## 系统概述

每天自动生成两份 HTML 简报，推送到 GitHub Pages 公网，手机/电脑均可访问。HTML 文件本身不依赖 JS 框架；图片允许使用稳定 HTTPS 远程地址，以保证 Hermes 可以稳定补齐配图。

| 📡 新闻联播深度解读 | 每晚 22:00 | `https://lizhenming008-dev.github.io/daily-briefing/` |
| 🤖 AI 热点早报 | 每天 9:00 |
| 🤖 AI 热点晚报 | 每天 21:00 |

## 二、推送脚本（push.sh）

```bash
#!/bin/bash
TOKEN="你的GitHub_Token"
DIR="/tmp/briefing-repo"
URL="https://${TOKEN}@github.com/lizhenming008-dev/daily-briefing.git"

if [ ! -d "$DIR/.git" ]; then
    rm -rf "$DIR"
    git clone "$URL" "$DIR"
fi
cd "$DIR"
git pull origin main --rebase
cp ~/Documents/每日简报/*.html . 2>/dev/null
git add *.html 2>/dev/null
git commit -m "update $(date +%Y%m%d)" 2>/dev/null
git push origin main
echo "done"
```

**用法**：AI 生成 HTML 后执行 `bash ~/Documents/每日简报/push.sh` 即可推送到公网。

**要求**：GitHub 上已有仓库 `lizhenming008-dev/daily-briefing`，Settings → Pages → Source: `Deploy from a branch`，Branch: `main / / (root)`。

## 三、新闻联播深度解读

### 3.1 数据来源
`https://cn.govopendata.com/xinwenlianbo/YYYYMMDD/`  
（将 YYYYMMDD 替换为当天日期，如 20260520）

### 3.2 提示词

```
你的任务是生成当天的《新闻联播》深度解读 HTML 文章，推送到公网。

## 步骤
1. 访问 https://cn.govopendata.com/xinwenlianbo/YYYYMMDD/ 获取全文（替换为今天日期）
2. 解析每条新闻，按以下六类排序：
   - 🇨🇳 时政要闻：高层讲话、政策发布、会议精神
   - 💰 经济财经：宏观经济数据、产业政策、贸易
   - 🏠 地产专项：房地产相关政策、市场动态（重点展开）
   - 🔬 科技前沿：科技突破、新基建、数字化
   - 🌍 国际观察：外交活动、国际关系
   - 📌 其他要点
3. 每条新闻写两个部分：
   - **表面意思**：1-2句话概括新闻说了什么（白话）
   - **深层解读**：2-3句话分析背后逻辑，回答"这意味着什么"（必须原创分析，不能复述原文）
4. 地产专项至少写 3 条解读（如果当天新闻不够，结合近期政策趋势补充）
5. 生成一个可独立访问的 HTML 文件，保存到 ~/Documents/每日简报/新闻联播_YYYYMMDD.html

## HTML 规范
- 文件名：新闻联播_YYYYMMDD.html（YYYYMMDD 为当天日期）
- CSS 内嵌 `<style>`；图片优先使用稳定 HTTPS 远程图片，不强制 base64
- 宽度 600px，手机竖屏优先
- 总大小建议 < 80KB（不要嵌入大段 base64，避免文件暴涨）
- 色调：深蓝 #1a1a2e 为主色，白色卡片，圆角 12px
- 顶部标题：📡 新闻联播深度解读 · YYYY年MM月DD日
- 每类一个卡片，卡片内有该类的条目
- 每条项目格式：
  - 标题（bold）
  - 📋 表面意思：...
  - 🔍 深层解读：...
- 底部：每日自动生成 · 全网可访问
- 每个卡片顶部必须配一张 16:9 配图；实在找不到新闻实图时使用主题占位图

## 图片合规与提取规则
- 优先提取新闻原文、政府/央媒/公司官网中的公开头图、`og:image`、产品截图或发布会配图，并在 `figcaption` 标明图片来源。
- 可使用新华社、央视、政府网站、公司官网、官方博客、GitHub 社交预览、arXiv 论文图、Unsplash/Pexels/Wikimedia Commons 等公开来源。
- 不要使用需要登录、付费订阅、明确禁止转载、带明显版权水印、私人社交账号、未成年人特写、血腥暴力、医疗隐私、身份证件、车牌等敏感图片。
- 不要下载并二次分发不明版权图片；优先用远程 HTTPS 链接引用，且保留来源说明。
- 如果无法确认版权或图片加载失败，使用主题 SVG/渐变占位图，不要硬凑。
- 每篇文章发布前必须人工或自动检查：新闻卡片是否有图、图片是否与标题相关、图片来源是否写清楚。

## 新闻联播配图关键词
| 分类 | 优先图片 | 兜底关键词 |
|---|---|---|
| 🇨🇳 时政要闻 | 央视/新华社/政府网站新闻图 | Beijing government meeting |

### 4.2 提示词

```
你的任务是搜索AI领域最新动态，生成公众号风格的HTML早晚报，推送到公网。

## 步骤
1. 搜索过去12小时AI重大新闻：
   - Hacker News 热门（API + 筛选 AI 相关）
   - 各大 AI 公司博客
   - arXiv 今日 AI 相关论文（选 2-3 篇）
   - 中国 AI 动态（量子位、机器之心等）
2. 选 8-10 条最有价值的新闻，按五类排序：
   - 🧠 新模型发布
   - 🛠️ 工具与产品
   - 💼 资本与商业
   - 🔬 前沿研究
   - 🏠 地产+AI（结合房地产行业的 AI 应用）
3. 每条新闻包含：
   - 标题 + 链接
   - 150字以内的要点总结
   - 对地产营销的启示（如果相关）
4. 每条新闻必须配一张相关图片：
   - 第一优先级：新闻原文或公司博客的 `og:image` / 文章头图
   - 第二优先级：公司 Logo、产品截图、论文图、GitHub 仓库社交预览图
   - 第三优先级：主题图（AI chip、robot、data center、research paper、real estate marketing 等）
   - 禁止 8-10 条新闻重复使用同一张图；同一类别最多复用 1 张
   - 图片用 HTTPS URL，不要转 base64；如果图片失效，用 CSS 渐变占位兜底
   - 合规要求：只使用公开可访问、可合理引用的新闻/官方/开放图库图片；不要使用付费墙、盗版、隐私、敏感、违法或明显不可转载的图片
5. 顶部写一段 100 字的「今日锐评」
6. 生成可独立访问的 HTML，保存到 ~/Documents/每日简报/AI热点_早报_YYYYMMDD.html 或 AI热点_晚报_YYYYMMDD.html

## HTML 规范
- CSS 内嵌；图片使用 HTTPS 远程 URL，总大小建议 < 80KB
- 宽度 600px，手机竖屏优化
- 公众号风格：白色背景，卡片式布局
- 顶部：🤖 AI 热点早报/晚报 · YYYY年MM月DD日
- 锐评区：左边框紫色 #7c3aed，浅紫背景 #f5f3ff
- 每条新闻一个卡片，含标题（可点击链接）、摘要、图片、地产启示
- 底部：每日自动生成 · 全网可访问

## 图片 HTML 模板（Hermes 必须照抄）
每条新闻卡片里的标题下方必须放置图片块：

```html
<figure class="media">
  <img class="news-img" src="https://example.com/image.jpg" alt="新闻主题关键词" loading="lazy" referrerpolicy="no-referrer" onerror="this.closest('.media').classList.add('is-fallback');this.remove();">
  <figcaption>图片来源：OpenAI / Google / arXiv / Unsplash</figcaption>
</figure>
```

CSS 必须包含：

```css
.media{margin:10px 0 12px;border-radius:8px;overflow:hidden;background:linear-gradient(135deg,#eef2ff,#f8fafc);border:1px solid #e5e7eb}
.media img{display:block;width:100%;aspect-ratio:16/9;object-fit:cover}
.media figcaption{font-size:11px;color:#888;padding:5px 8px;background:#fafafa}
.media.is-fallback{height:150px;display:flex;align-items:end;background:linear-gradient(135deg,#1a1a2e,#7c3aed)}
.media.is-fallback::before{content:"AI Briefing";color:#fff;font-weight:700;font-size:18px;margin:auto}
.media.is-fallback figcaption{display:none}
```

## 发布前自检
生成 HTML 后，Hermes 必须自查：
- 新闻条目数 = `.card` 数量（或新闻卡片数量）
- 图片数 = `.news-img` 数量，必须不少于新闻条目数的 80%
- 图片 `src` 必须是 `https://` 或 `data:image/svg+xml`
- 每张图片都必须有 `alt` 和 `figcaption`，`figcaption` 写清楚来源
- 如果图片数不足，先补图再执行 push.sh
- 如果图片版权或内容合规性不确定，替换为官方 Logo、产品截图、开放图库图或 SVG/渐变占位图
- 不要为了凑图使用同一张 base64 大图反复复制
